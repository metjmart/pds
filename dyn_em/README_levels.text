
This modified version of module_quarter_ss.F also contains code that
makes it possible to read in the vertical levels from a file.

Here you can see some changes to the code:

! Dave Nolan: remember "false" here means not stretched in eta (WRF coordinates)
!   stretch_grid = .true.
   stretch_grid = .false.
   manual_grid = .false.

and later:

! Dave Nolan/Stefan:
   IF (manual_grid) THEN
    print *,'MANUALLY SPECIFYING ZNW NOW'
    open(unit=13,file='grd',form='formatted',status='old')
   DO k=1, kde
     read(13,*) grid%znw(k)
     print *,'full level value = ',grid%znw(k)
    ENDDO
    close(unit=13)


So, if you want to read the vertical levels in from a file,
change the code to say manual_grid = .true., then re-compile.

"grd" should be a text file containing one vertical level (eta)
value on each line from 1 to 0. For example, here is a file
for 26 vertical levels (which means 25 half-levels):
